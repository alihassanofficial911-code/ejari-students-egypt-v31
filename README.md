# منصة إيجاري طلاب مصر v3.1 | Ejari Students Egypt (Production-Ready)

منصة وسيطة سحابية (SaaS) متكاملة لإدارة وتأجير سكن الطلاب المغتربين والوافدين قرب الجامعات في المحافظات المصرية، متوافقة مع بوابات الدفع المصرية (Paymob, InstaPay, Vodafone Cash, Fawry)، خرائط الحرم الجامعي التفاعلية Leaflet.js، توثيق JWT المتقدم، ونظام إشعارات أولياء الأمور الفورية عبر واتساب.

---

## 🏛️ الجديد في الإصدار v3.1 الإنتاجي (What's New in v3.1)

1. **خرائط الحرم الجامعي التفاعلية ومسارات السير (Interactive Leaflet Map & Routes):**
   - دمج مكتبة `Leaflet.js` مع دبابيس تفاعلية لمواقع الشقق وبوابات الجامعات المصرية الرئيسية.
   - رسم خط مسار سير متقطع (`Polyline`) يوضح الطريق والمسافة بالدقائق بين السكن وبوابة الجامعة.
   - زر "📍 الخريطة والمسار" في كل بطاقة للتحليق المباشر (`flyTo`) وفتح النافذة التفاعلية.

2. **نظام تقييمات ومراجعات الطلاب الفصلي (`/api/reviews`):**
   - جدول `reviews` لتسجيل مراجعات وتقييمات الطلاب بعد انتهاء الفصول الدراسية.
   - إعادة الحساب التلقائي لمتوسط التقييم (`rating_avg`) وعدد المراجعات (`reviews_count`) في جدول العقارات فور إضافة تقييم جديد.

3. **بوابة إشعارات أولياء الأمور الفورية عبر واتساب (`/api/notifications/parent-alert`):**
   - محاكي `WhatsApp Cloud API` لإرسال تذكيرات الإيجار الشهري وإيصالات إيداع مبالغ التأمين في حساب الضمان (`Escrow`).
   - إرسال إشعار تلقائي لولي أمر الطالب فور حجز السرير أو سداد القسط.
   - سجل موثق للإشعارات المرسلة مع إشعارات منبثقة (`Toast`) فورية.

4. **توثيق أمني قياسي عبر `JWT` (`HS256`) وتشفير كلمات المرور:**
   - توثيق الجلسات عبر `JWT` مع صلاحية زمنية ومزخرف `@jwt_required`.
   - تشفير كلمات المرور باستخدام `Werkzeug / PBKDF2` لجميع الحسابات، وتحديث حسابات الـ Demo التجريبية الثلاثة لتعمل مشفرة.

5. **دعم قواعد البيانات الهجين (SQLite محلياً + PostgreSQL إنتاجياً):**
   - قراءة المتغير البيئي `DATABASE_URL` والاتصال بـ `PostgreSQL` على السحابة، مع العودة التلقائية لـ `SQLite` في التطوير المحلي.

6. **فحص جاهزية الخادم (Health Check Endpoint):**
   - مسار `GET /api/health` لمراقبة حالة الخادم، الإصدار `3.1.0`، حالة `JWT`، ونوع قاعدة البيانات المتصلة.

## 🚀 طريقة التشغيل والاختبار الآلي

### 1. تشغيل الاختبارات الآلية (10/10 Tests Passed):
```bash
python -m unittest discover -s backend -p "test_*.py" -v
```

### 2. تشغيل الخادم المحلي:
```bash
python backend/app.py
```
أو عبر خادم الإنتاج `Gunicorn`:
```bash
gunicorn -w 3 -b 0.0.0.0:5000 backend.app:app
```
ثم افتح المتصفح على الرابط:
👉 **http://127.0.0.1:5000**
